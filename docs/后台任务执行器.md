# 后台任务执行器

## 行为与边界

普通聊天提交后，Rust 后台任务持有执行权，负责上下文检索与预算、滚动摘要、流式模型调用、计划更新、工具审批与执行、结果续写和澄清。前端只提交请求、订阅进度和提交用户决定。

- 切换会话、切换到服务器管理或定时任务页面、关闭当前会话视图，都不会取消任务。
- 不同会话可以同时执行；同一会话同时最多一个后台任务，包括等待审批或澄清的任务。
- 模型 ID、工作目录、审批模式、命令开关及基础技能/MCP 提示在提交时绑定，不随另一个会话的选择改变。每轮仍重新校验实际工具策略与当前 MCP 连接范围。
- 每轮从原会话数据库加载历史，并重新检索记忆、画像、项目索引和该会话的 RAG。普通会话不自动检索其他会话共享临时目录的项目索引。
- 切回运行会话时读取后台流式缓冲与运行时间线；完成的消息、推理片段、计划和工具结果保存在原会话。
- 生成、执行等忙碌状态按当前会话显示；A 执行时，B 可以继续发送消息。事件和异步加载都校验会话 ID，后台结果不会切换当前选中的会话。

应用完全退出后进程停止，后台任务不会在操作系统中继续。启动时沿用运行时恢复规则：未完成模型调用标为失败，执行中工具标为结果未知、等待人工恢复；等待审批或澄清的后台任务恢复等待，不自动重放结果未知的工具。

## 计划、审批与停止

复杂任务使用已有 `<task_plan>` 协议。模型只生成计划、计划仍有 `pending/in_progress` 步骤时，后台继续推进，不直接标记完成；计划出现阻塞且无工具/澄清请求时进入待恢复。计划不是工具成功的证明，步骤仍须根据真实结果更新。每次人工启动或恢复最多连续推进 64 轮，达到上限后进入待恢复，可检查后继续。

审批模式保持现有语义：请求批准逐次确认，帮我批准自动执行允许的低/中风险操作，完全访问自动执行策略允许项。手动批准/拒绝只修改后台决策，执行和续写由后台完成。工具失败不自动重复副作用，进入待恢复；显式重试沿用工具最多 3 次的尝试限制，跳过失败后继续会写入恢复说明。自动澄清采用推荐项，缺少推荐标记时沿用第一项，手动/自动选择均写入审计步骤。

流式输出中的停止按钮，以及准备、工具执行或等待决定时的「停止任务」，均针对当前会话的后台任务。停止模型生成会保留部分正文与推理；取消等待审批的工具不会执行，并清理决策状态。已经开始的工具先运行到已记录结果或原有超时，再停止后续模型调用，避免把取消信号误当成副作用已撤销。生成和等待任务的会话不能直接删除，需要先停止。

重新生成普通回答同样进入后台。成功后在数据库保存点中替换旧回答；失败或停止保留旧回答，已输出的部分内容单独保留。

## 实现与持久化

- `src-tauri/src/background_agent.rs`：应用级任务所有权、取消/唤醒信号、流式缓冲、后台模型/工具循环、审批与恢复 IPC。
- `src/hooks/useChat.ts`：提交请求、会话范围内的展示投影、审批/澄清交互。原前端工具执行 Hook 已移除。
- `src/lib/backgroundAgent.ts`：IPC 类型和会话投影辅助函数。
- `agent_execution_requests`：位于运行时库，以 run ID 为主键保存执行上下文，用于重启后的审批、澄清、失败恢复；不重复存储模型 API Key。
- 消息 `metadata.assistant_reasoning`：可选推理片段；旧消息无需迁移。
- IPC：`start_background_agent`、`list_background_agents`、`respond_background_agent`、`stop_background_agent`。
- 事件：`background-agent`，始终包含原 run ID 和会话 ID。无人订阅或页面卸载不会影响执行。

模型流式调用最长 300 秒，工具沿用现有 150 秒总超时和脚本 45 秒超时。此前的 `chat/chat_stream` 等底层接口仍保留，普通聊天不再靠前端调用它们来续写。

## 验收与验证

完成标准：

1. A 提交有计划和工具的任务，切换 B，A 继续推进并只修改 A 的目录。
2. A 运行时 B 能发起独立任务，两者保持自己的模型、历史和工作目录。
3. 切回 A 能看到当前缓冲或已保存成果；切换页面及卸载聊天观察者不触发取消。
4. 原审批、澄清、停止、工具重试、恢复、重新生成行为保留。
5. 计划与最终消息持续保存到原 run/会话，后台完成不会强制导航。

Rust 测试直接运行生产执行循环，使用本地 OpenAI 兼容 SSE 服务和真实文件工具，覆盖计划推进、写入/读取验证、并发会话、审批唤醒、澄清、显式重试、停止与原会话持久化，并验证推理保存、长历史摘要和模型观测记录。前端测试覆盖跨会话事件过滤、缓冲恢复与忙碌投影。浏览器测试运行实际 React `useChat`，使用模拟 Tauri IPC 验证切换 A/B、B 提交、切换页面、卸载/挂载和停止当前任务；模拟 IPC 不能代替用户模型服务或完整 WebView 的联调证明。
