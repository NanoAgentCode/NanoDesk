# 提示词组装与预算

后台任务的静态提示由 `src/lib/chatSystemMessage.ts` 生成；传入 `deferRetrieval=true` 时，任务规划与代码搜索规则交给后端统一注入。独立调用仍保留完整规则。工具 XML 协议保留参数格式与执行顺序，减少重复说明。

`src-tauri/src/agents/background_agent/context.rs` 负责运行时状态、授权、规划、恢复规则和检索上下文。`prompt_context.rs` 单独控制检索证据：

- 按记忆、代码、项目资料、上传资料的原有顺序组装，正文完全相同时只保留首个来源。
- 单条最多 2,400 个 Unicode 字符，总计最多 12,000 个字符（包含来源和截断标记）。截断明确提示按来源读取全文。
- 不再每轮附加最多 300 项的项目文件清单；通过检索来源或限定目录工具继续定位。
- 核心指令、用户画像、规划、授权和中断恢复信息不进入这个证据预算；历史摘要和模型总上下文预算仍由 `context_budget.rs` 管理。

字符上限是确定性的负载控制，不等同于模型实际 token 数。工具协议源码段由 879 字符缩至 557 字符，减少约 37%；后台请求还去除了重复的前端规划和搜索说明。整体 token 降幅取决于检索量、历史长度和模型 tokenizer，不能用局部字符降幅代替真实用量。

验证覆盖 Unicode 截断、去重、来源保留、总预算、后台规则委托和工具协议完整性，并运行前后端回归测试。
