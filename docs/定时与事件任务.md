# 定时与事件任务

## 使用

在侧栏进入「定时与事件任务」，点击「新建任务」。填写名称、工作目录、执行内容及触发规则，保存后启用。支持编辑、暂停、删除、立即执行，以及查看最近 100 条执行记录。暂停会取消尚未开始的入队和延迟重试；正在执行的任务允许结束，暂停后不再自动重试。删除会删除配置和记录，保留已经生成的成果文件；执行中不能删除。

### 执行内容

- **AI 办公任务**：选择已有聊天模型，填写提示词，可指定目录内的 UTF-8 文本相对路径，每行一个。每个文件最多 64KB、最多 20 个，整个输入最多 256KB。读取仍经过项目路径安全策略；结果保存为 `.nanodesk/automation/<执行ID>-<尝试次数>.md`，同时显示在执行详情中。模型调用最长 180 秒。第一版生成文本成果，不执行聊天 Agent 工具循环，不自动读取变化文件，不抽取 PDF/Word/Excel；需要处理这些文件时可配置脚本。
- **本地脚本命令**：保存时明确确认后台执行授权；执行时仍经过现有命令安全策略，在指定工作目录运行，最长 45 秒。输出和错误写入执行记录。配置自动重试时，脚本应能够安全重复执行；默认重试次数为 0。

任务可在聊天页面之外执行，不依赖当前选中的会话，也不把预设提示词作为用户画像样本。

## 触发规则

| 类型 | 行为 |
| --- | --- |
| 单次 | 本机时区选择未来时间，保存为 UTC 时间戳；自动触发后清除下次时间 |
| 固定间隔 | 保存后等待指定秒数；后续沿原定时间序列推进，最短 10 秒 |
| 每日 | 使用保存的小时、分钟和 UTC 偏移，默认取创建时本机偏移；旅行或夏令时变化时需要编辑偏移 |
| 文件变化 | 每 2 秒扫描目录中的新增、修改、删除，通过文件大小和修改时间判断变化；可选择递归子目录，稳定达到防抖时间后合并触发一次 |

文件监听首次保存时建立基线，已有文件不会触发任务。忽略 `.git`、`.codegraph`、`.nanodesk`、`node_modules`、`target` 目录及符号链接，避免成果写入引发循环；最大 20000 个文件。扫描失败不把无法访问的目录当成全部文件被删除，而是在任务卡显示错误；恢复访问后继续对比。两次扫描之间出现又消失的短暂变化，以及大小和修改时间都未改变的内容修改，可能无法捕获。

同一任务同时最多存在一条未处理记录，防抖期间路径会合并；执行期间新变化保留，结束后再触发。不同任务进入同一队列，第一版串行执行，触发扫描独立于执行 worker。

## 重试与补执行

- **失败后延迟重试**：最多 0–10 次额外重试，每次等待指定秒数（5–86400 秒）。等待时间、已尝试次数和错误持久化，重启后继续等待或执行已经到期的重试。
- **合并补执行一次**：定时任务错过多个时间点时合并入队一次，再将游标推进到未来；文件任务保留快照，下次启动或重新启用后对比离线期间变化，合并触发一次。
- **跳过**：跳过超过调度宽限时间的定时触发，继续等待未来时间；文件任务启动和重新启用时重建基线，忽略停用期间变化。正常轮询允许 5 秒调度宽限。
- **结果未知**：应用重启时，原来的执行中记录标为结果未知。脚本超时也标为结果未知，不自动重试。同一任务会暂停继续触发，直到用户检查实际结果，选择「重新执行」或「忽略」。重新执行需要确认，失败记录也允许手动重新执行。

应用运行或驻留系统托盘时调度；完全退出和电脑休眠期间不执行。再次运行或唤醒后按以上规则处理。不会安装系统计划任务，也不会在退出后启动应用。

## 实现与数据

- 后端：`src-tauri/src/automation.rs`；触发扫描 worker 与执行 worker 分离。
- 前端：`src/components/AutomationPanel.tsx`，作为主视图插件注册。
- IPC：`list_automations`、`save_automation`、`set_automation_enabled`、`delete_automation`、`list_automation_runs`、`run_automation_now`、`recover_automation_run`。
- 数据库：app data 下的 `nanodesk-automation.sqlite3`，SQLite WAL。
- 触发游标与新执行记录在同一事务提交；领取任务也在事务中修改状态。执行记录保留当时配置，重试使用该配置，不因后续编辑改变。
- 配置存在未处理记录时不能编辑；可先暂停取消待执行记录，或处理失败/结果未知记录。
- 执行结果通过 `automation-changed` 事件更新当前任务界面，并记录操作日志；第一版无系统通知和外部消息发送。
