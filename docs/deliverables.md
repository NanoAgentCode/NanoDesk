# 对话交付物

主窗口右侧任务面板包含“任务规划”和“交付物”两个选项卡，沿用面板收起和宽度调整。

- **用户上传**：当前对话的文档附件和已发送的图片附件。
- **中间文件**：当前对话中 `write_file` 工具成功写入的文件，同一路径合并展示。
- **最终交付**：助手回复通过 Markdown 文件链接交付的文件，需要有成功写入记录或存在于当前项目文件清单中。

有本地路径的文件可点击文件夹按钮定位；文档附件由对话索引保存，没有原始路径时仅显示名称。切换对话后仅展示对应对话的记录。

文件分类使用已有对话和工具历史，不扫描整个项目。失败、待批准的写入，以及没有写入记录、也不在项目文件清单中的链接不会计为生成文件。命令或外部工具生成的文件，若通过回复链接交付且已出现在项目文件清单中，也会展示；没有写入记录或交付链接的中间文件暂不自动归集。文件被外部删除或移动后定位可能失败，面板会显示错误。
