# 工作流画布

在侧栏打开「工作流」，新建画布。每个工作流独立保存，包含节点配置、坐标、连线和运行记录。

## 编辑

- 将上方的 AI 提示词、条件或汇合按钮拖到画布，在落点创建节点；拖动时显示位置预览，支持缩放和滚动后的坐标。也可点击按钮添加。创建后自动选中节点，在右侧编辑内容；运行过程中禁止新增。
- 拖动节点标题调整位置；画布可滚动，使用工具栏的加减按钮缩放。
- 每个节点左侧有一个输入端点、右侧有一个输出端点。从上游输出端点拖到下游输入端点即可建立连线；拖动时显示虚线预览，松开在空白处取消。也可选择顶部起点和终点后点击「连接」。条件节点拖线前选择上方「条件为真」或「条件为假」，一个输出端点可建立多条不同分支的连线。同一出口可以连接多个节点，自动并行执行。重复连线、自连和循环连线会被拒绝；运行时禁止拖线。
- 右侧连线列表可删除连线。删除节点会删除关联连线；自连或形成循环的连线会被拒绝。
- AI 节点可以选择模型，也可使用工具栏的默认模型。更改默认模型只影响后续调用。

## 数据与条件

提示词通过 `{{节点ID.output}}` 引用上游输出，节点 ID 显示在右侧设置中。只有直接或间接连通的上游可以引用，不自动继承聊天历史。

AI 节点包含独立的「系统提示词」和「用户提示词」：系统提示词定义角色、行为约束和输出要求，用户提示词描述本节点任务。两者分别以 system、user 消息发送，均可使用上游变量；运行记录分别保留解析后的内容。旧版提示词继续作为用户提示词，系统提示词默认为空。

设置画布上的项目绝对路径后，AI 节点会获得已接入的本地工具和当前已连接的 MCP 工具列表，自行决定是否需要调用、选择工具并生成参数。工具结果回传给模型，模型继续执行或给出最终答案；不需要工具时不产生工具操作。项目目录留空时仅生成文本。模型和工具交互每个节点最多执行 12 次工具调用，达到上限则显示失败，避免无限执行；这不改变画布禁止循环的规则。AI 条件节点只做判断，不调用工具。

旧画布中的独立工具节点会转换为 AI 节点，保留 ID、位置与连线，并将原工具名及参数写入用户提示词；由 AI 重新判断，不强制执行原操作。

规则条件支持「包含」「等于」「数值大于」，比较值也可引用上游输出。AI 条件根据填写的指令判断，只接受严格的 `true` 或 `false`；其他回答显示失败。

汇合节点等待本次活动路径完成，按连线顺序用空行拼接上游结果。条件未选中的分支及其后续节点跳过，不参与等待。活动路径失败时，汇合节点被阻断。

## 运行

- **运行全部**：从头执行整个工作流，独立分支并行执行。
- **运行节点**：每个节点都有独立按钮。需要已有的上游结果；缺失时提示先运行上游。修改节点配置或连线后，旧配置的结果不能继续使用。重新执行上游会使下游旧结果失效。
- **重试并继续**：失败节点提供重试按钮，重新执行该节点及其下游，保留独立分支的已有结果。不会自动重试工具，避免意外重复副作用。
- **停止**：取消正在生成的模型请求，不再调度下游。已发出的工具调用可能继续完成当前操作，停止不能撤销已发生的文件或外部服务修改。等待工具审批时，可取消审批结束当前节点。
- 运行过程中禁止修改配置。离开工作流页面会停止当前调度；请保持页面打开直到完成。

工具需要填写项目绝对路径，并复用现有工具策略和访问模式。命令工具还需要勾选「允许命令工具」，权限策略仍可能拒绝或要求审批。多个并行 AI 节点的工具审批按顺序展示。工具审计记录使用归档会话保存，不混入普通聊天列表。

## 保存与记录

画布与记录自动保存在当前应用 WebView 的本地存储中（`<应用前缀>-workflows-v1`），不进入聊天数据库。记录保留运行时的画布快照、节点输入、输出、状态、分支选择和错误。右侧可选择历史记录；历史记录中的输出不会作为新的运行输入。

存储配额不足时显示保存失败，当前内容仍在页面内；关闭前应处理存储问题。无法解析存档时停止写入，保留原存档。重新进入后，未完成的节点标记为已停止，不自动恢复工具操作。删除工作流同时删除其画布运行记录，工具审计会话仍保留。

## 验证

`src/lib/workflow.test.ts` 覆盖调度和变量语义，`src/lib/workflowRuntime.test.ts` 覆盖模拟 IPC 的模型取消、工具审批和拒绝。`scripts/test-workflow-ui.py` 使用本机 Edge 和模拟 IPC 验证画布交互，可运行：

先运行 `npm run dev -- --host 127.0.0.1`，再在另一个终端运行 `python scripts/test-workflow-ui.py`。需要安装 Python Playwright，并已安装 Microsoft Edge。

这些模拟测试不证明真实供应商或外部 MCP 服务的可用性。
