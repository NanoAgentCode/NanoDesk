| 维护 FTS 表不代表召回已经查询该表 | [memory_store.rs](../src-tauri/src/db/memory_store.rs) 聊天词项评分；[code_index_store.rs](../src-tauri/src/db/code_index_store.rs)、[project_index_store.rs](../src-tauri/src/db/project_index_store.rs) 的 LIKE/向量支路；RAG 无 FTS 降级 |

| Shell 工作目录不等于文件系统沙箱；MCP 风险按名称推断 | [shell.rs](../src-tauri/src/shell.rs)、[tool_policy.rs](../src-tauri/src/tool_policy.rs)；后端授权检查当前 session 工具列表，没有本次提示词 scope 快照 |
