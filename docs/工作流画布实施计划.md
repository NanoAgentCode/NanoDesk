# 工作流画布

## 范围与验收

独立入口管理多个本地工作流；可拖动节点和连线；AI、规则条件、AI 条件、汇合节点；AI 节点分别配置系统/用户提示词，自主判断工具调用；禁止循环。
支持整图自动运行和每个节点单独运行。变量引用上游输出，条件未选中路径跳过，汇合等待实际执行路径。
失败仅阻断相关下游，独立分支继续；手动重试后可继续；可停止，保留每次输入、输出、状态、错误。
工具复用现有审批与执行接口，模型复用现有配置。

## 实施步骤和验证

1. 数据结构、DAG 校验、变量和执行器：单元测试覆盖并行、条件、汇合、失败隔离、重试、停止、单节点依赖。
2. 模型和工具适配器：核对真实 IPC 参数，测试审批、取消和错误传播。
3. 画布与本地存储：接入主视图，验证编辑、拖动、连线、删除、保存恢复、运行记录。
4. 更新 README 和使用文档，运行前端测试、类型检查与生产构建，检查界面。
