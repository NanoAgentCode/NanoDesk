# 桌面助手模式

## 使用

在「系统设置 → 通用设置 → 系统选项」开启 **显示桌面助手**。此开关默认关闭，开启后显示桌面置顶图标；关闭后立即隐藏助手。选择保存在本机，应用再次启动时恢复。

- 点击图标展开白色圆角输入条，输入文字后按 Enter 或点击发送，创建新的普通会话。
- 输入 `@` 显示已有会话；继续输入会话名或项目路径过滤。可点击选择，也可用上下方向键和 Enter 选择。选择后输入消息并发送，继续该会话的历史上下文、模型配置和项目范围。
- 已选择会话显示为输入条中的标签；点击标签取消选择，或点击左侧加号切换到新聊天。加号保留已输入的正文。
- 发送后打开主窗口展示聊天与结果，助手收起为图标。后续工具审批、澄清、停止任务等沿用主窗口。
- 按 Esc 或点击收起按钮回到图标；未发送的输入保留。拖动图标或输入条上方「桌面助手」区域移动窗口。
- 图标和输入条的右键菜单仅提供「关闭」，隐藏助手并关闭通用设置中的开关。可从通用设置重新开启。

主窗口已有未发送文字、图片附件、正在处理附件或语音，或目标会话正在执行任务时，助手保留输入并提示先处理主窗口内容。会话在选择后被删除、归档或项目入口移除时，发送会被拒绝，需要重新选择。助手只提供文本快捷入口。

应用最小化到托盘时，已开启的助手继续可用；完全退出应用后图标消失。助手开关与 Windows 开机自启动分别控制。

## 实现

独立 `assistant` Tauri Webview 使用透明、无边框、置顶且不显示任务栏按钮的窗口。图标、输入和候选列表使用不同窗口尺寸，展开和收起尽量保持右下角锚点，并限制在显示器工作区内，支持显示器缩放。

`AssistantMode` 负责输入、会话搜索与选择。`useAssistantHandoff` 在主窗口验证目标和模型、创建或切换会话，并调用 `useChat.handleAssistantMessage`，复用消息持久化、模型路由、上下文准备与后台任务流程。跨窗口事件使用请求 ID 匹配确认；错误时保留助手输入，接收成功后清空并收起。

## 验证

- `npm test`：会话匹配、提及范围、归档排除、草稿与任务保护、开关持久化、事件确认和 IPC 契约。
- `npm run build`：TypeScript 与前端生产构建。
- `cargo check --manifest-path src-tauri/Cargo.toml --lib`：原生窗口实现编译检查。
- 浏览器交互检查：新会话、普通及项目会话续聊、键盘选择、归档隐藏、草稿及任务保护、Esc 收起；使用模拟 IPC 和聊天发送器，不能替代真实模型调用验收。
- Windows 原生检查：通用设置开关显示、隐藏和重新显示助手；置顶状态及图标、输入条、候选列表的尺寸切换。在 150% 系统缩放下通过。
