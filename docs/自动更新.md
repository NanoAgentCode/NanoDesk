# 自动检查更新

主窗口启动 5 秒后检查一次，此后每 6 小时检查 GitHub 仓库 `NanoAgentCode/NanoDesk` 的最新稳定 Release。仅提示高于当前应用版本、且包含当前架构安装包的版本；忽略草稿和预发布版本。同一版本每次启动最多自动提示一次。

「系统设置 → 更新应用」显示已安装应用的当前版本，提供「更新日志」与「检查更新」入口。更新日志通过系统浏览器打开官方 GitHub Releases 页面；手动检查期间按钮显示「正在检查…」并禁止重复点击。发现新版后复用下载弹窗（即使此前选择了稍后再说）；无可用更新时显示结果，网络或限流失败时显示错误并允许重试。手动检查不改变自动检查的周期。

弹窗显示版本号及更新说明。「从 GitHub 下载」使用系统浏览器打开官方 Release 安装包链接，下载完成后由用户运行安装；「稍后再说」关闭提示。打开浏览器失败时可重试。检查失败（包括离线、超时、GitHub 限流）不打断聊天，下个周期重试。

发布时需同步维护 Cargo.toml、tauri.conf.json 和 package.json 中的版本号，创建正式 GitHub Release，并上传对应安装包，名称以 `_x64-setup.exe` 或 `_arm64-setup.exe` 结尾。仅推送 Git 标签或上传 Actions 构建产物不会触发更新提示。当前应用打包目标为 Windows NSIS，功能不自动安装或重启应用。
