# 语音识别（ASR）

NanoDesk 支持在聊天输入区录音或选择音频文件，调用兼容 OpenAI 的 ASR 服务，将识别结果追加到输入框。文字可继续编辑，由用户点击发送。

## 配置

打开 **系统设置 → 语音识别**，填写并保存：

| 配置项 | 说明 |
| --- | --- |
| 服务地址 | 服务根地址（包含 `/v1`）或完整 `/v1/audio/transcriptions` 地址；完整地址直接使用，根地址追加 `/audio/transcriptions` |
| API Key | 服务认证密钥；本地无鉴权服务可留空 |
| ASR 模型名称 | 服务商提供的准确模型 ID |
| 语言 | 可选两位语言代码，例如 `zh`、`en`；仅在服务支持 `language` 时填写，留空不发送此参数 |

设置页预填用户指定的硅基流动配置：

```text
服务地址：https://api.siliconflow.cn/v1/audio/transcriptions
模型名称：Qwen/Qwen3-ASR-1.7B
```

填写自己的 API Key 后保存。可以点击“选择音频测试”，用当前表单配置实际上传一段音频，检查返回文字；测试不会自动保存配置，也不会创建聊天消息。

配置保存在应用数据目录的 `settings.json` 的 `asr` 字段中，与 Tavily 配置并存。旧版本设置文件不含该字段时仍能正常读取。API Key 按现有设置方式保存为本地明文，表单默认隐藏显示。

## 使用

- **录音**：点击聊天输入区的麦克风按钮，允许麦克风访问；录音中显示秒数，再次点击停止按钮后识别。录音最多 5 分钟，到时自动停止并识别。
- **音频文件**：点击麦克风旁的音频文件按钮，选择 WAV、MP3、M4A、MP4、MPEG、MPGA 或 WebM 文件；单文件最多 25 MB，实际格式支持与时长限制以服务商为准。
- **编辑与发送**：识别文字追加到当前草稿，保留手工输入；检查或修改后点击发送。
- **取消**：语音处理中可以取消。取消、切换会话/项目、离开聊天视图或进入生成/待决策状态时，不再填入该次识别结果。麦克风资源会释放。已经发送的 HTTP 请求可能仍在服务端执行。

录音由 WebView 的 MediaRecorder 获取，停止后转换为 16 kHz 单声道 PCM WAV，再上传到 ASR 服务。音频文件按原格式上传，原始音频不写入聊天记录或项目附件目录。

## 接口与边界

前端通过 Tauri `transcribe_audio` command 将音频传给 Rust，Rust 使用 `multipart/form-data` POST 上传 `file`、`model`，仅在填写语言时增加 `language`。配置了密钥时发送 `Authorization: Bearer …`；服务应返回包含字符串 `text` 的 JSON。请求超时为 120 秒。

该实现参照 [OpenAI 转录接口](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create) 和 [硅基流动转录接口](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)，使用两者共同的必填字段。模型名称由用户配置，不使用服务商文档中的枚举硬编码限制。

当前提供停止录音后的整段转录，不包含实时流式字幕、说话人识别、音频分段或长文件自动切分。生成回复或等待工具/澄清决策时，语音输入与普通输入同步锁定。

## 验证与排查

前端测试覆盖草稿追加、配置/文件校验、WAV 编码、录音取消与资源释放；Rust 测试通过本地 HTTP 模拟服务覆盖地址拼接、multipart 音频/模型/语言字段、认证、成功结果及错误响应，并验证旧设置兼容和配置序列化。

- 麦克风访问被拒绝：检查 Windows 隐私设置中桌面应用的麦克风权限。
- HTTP 401/403：检查 API Key 和模型权限。
- HTTP 404：检查完整接口地址和模型名称。
- HTTP 413：服务商限制更小，缩短音频或减小文件。
- HTTP 429：检查余额、额度或频率限制。
- 无识别文字：检查录音内容，以及服务是否返回 `{ "text": "…" }`。
- 超时：检查网络，重试或使用更短的音频。
