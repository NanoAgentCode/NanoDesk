# 语音识别（ASR）

NanoDesk 支持在聊天输入区录音、通过统一附件按钮选择音频，或直接拖入音频文件，调用兼容 OpenAI 的 ASR 服务，将识别结果追加到输入框。文字可继续编辑，由用户点击发送。

## 配置

打开 **系统设置 → 供应商管理**，添加兼容 OpenAI 的服务地址和 API Key，再到 **系统设置 → 模型路由 → 语音识别模型（ASR）**，从“供应商 / 模型”列表选择 ASR 模型。选择后立即自动保存，不再提供独立语音识别设置页。

硅基流动示例：

```text
供应商服务地址：https://api.siliconflow.cn/v1
模型名称：Qwen/Qwen3-ASR-1.7B
```

语音识别复用供应商的地址和 API Key；每次调用都读取供应商的最新配置。修改供应商密钥后无需在 ASR 中重复填写。删除已选择的供应商后，需要重新选择模型。

“识别语言（可选）”可填写 `zh`、`en` 等两位语言代码，失去焦点后保存；仅在服务支持 `language` 参数时填写，留空不发送此参数。点击选择器旁的音频测试按钮，可上传一段音频检查当前识别配置；测试不会创建聊天消息。

`settings.json` 的 `asr` 字段保存供应商 ID、模型名称和可选语言，与 Tavily 配置并存；绑定供应商时 `base_url`、`api_key` 字段仍存在但为空字符串，不复制凭据。旧版本独立 ASR 配置仍可使用；若能唯一匹配已有供应商，会在选择器中显示，重新选择模型或保存语言后转为供应商引用。无法匹配时提示沿用旧配置，可从供应商重新选择。供应商 API Key 按现有方式保存为本地明文。

## 使用

- **录音**：点击聊天输入区的麦克风按钮，允许麦克风访问；录音中显示秒数，再次点击停止按钮后识别。录音最多 5 分钟，到时自动停止并识别。
- **附件选择与拖拽**：点击麦克风旁的回形针“添加附件”按钮，或拖入 WAV、MP3、M4A、MP4、MPEG、MPGA 或 WebM 文件；单文件最多 25 MB，实际格式支持与时长限制以服务商为准。多个音频按顺序识别并追加到草稿。
- **混合附件**：可一次选择或拖入图片、音频和文档。图片继续作为图片附件，音频调用 ASR，文档继续抽取文本并索引到当前对话；音频不进入文档文本提取。单个文件失败不影响其他文件，结果提示同时列出成功与失败。
- **编辑与发送**：识别文字追加到当前草稿，保留手工输入；检查或修改后点击发送。
- **取消**：语音处理中可以取消。取消、切换会话/项目或离开聊天视图后，当前音频及该批剩余音频不再填入草稿；回到聊天区后可以开始新一批附件上传。麦克风资源会释放，已发送的 HTTP 请求可能仍在服务端执行。生成或等待工具/澄清决策时暂停接收附件；附件或录音处理中保留文本编辑，发送需等待处理完成或先取消语音输入。

录音由 WebView 的 MediaRecorder 获取，停止后转换为 16 kHz 单声道 PCM WAV，再上传到 ASR 服务。音频文件按原格式上传，原始音频不写入聊天记录或项目附件目录。

## 接口与边界

浏览器文件选择和录音通过 Tauri `transcribe_audio` command 传输音频；桌面拖拽通过 `transcribe_audio_file` 按二进制读取本地文件，在读取前和读取后检查 25 MB 限制。Rust 使用 `multipart/form-data` POST 上传 `file`、`model`，仅在填写语言时增加 `language`。配置了密钥时发送 `Authorization: Bearer …`；服务应返回包含字符串 `text` 的 JSON。请求超时为 120 秒。

该实现参照 [OpenAI 转录接口](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create) 和 [硅基流动转录接口](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)，使用两者共同的必填字段。模型由供应商列表选择，不使用服务商文档中的枚举硬编码限制。

当前提供停止录音后的整段转录，不包含实时流式字幕、说话人识别、音频分段或长文件自动切分。生成回复或等待工具/澄清决策时，语音输入与普通输入同步锁定。

## 验证与排查

仓库前端测试覆盖附件分类、混合处理结果、供应商选择、ASR 与聊天/嵌入模型隔离、旧配置匹配、草稿追加、配置/文件校验、WAV 编码和录音资源释放。Rust 测试验证本地音频二进制读取、格式/大小限制，并通过本地 HTTP 模拟服务覆盖地址拼接、multipart 字段、认证和响应处理，同时验证供应商引用及旧设置兼容。仓库未提供可复跑的真实 WebView/聊天 hook 浏览器集成测试；统一文件入口、桌面拖拽、取消、切换会话和真实麦克风权限仍应在实际客户端联调，不将模拟协议测试视为真实服务识别验证。

- 麦克风访问被拒绝：检查 Windows 隐私设置中桌面应用的麦克风权限。
- HTTP 401/403：检查 API Key 和模型权限。
- HTTP 404：检查完整接口地址和模型名称。
- HTTP 413：服务商限制更小，缩短音频或减小文件。
- HTTP 429：检查余额、额度或频率限制。
- 无识别文字：检查录音内容，以及服务是否返回 `{ "text": "…" }`。
- 超时：检查网络，重试或使用更短的音频。
